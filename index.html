Application 1 — Slide 01 / 05

Intelligent Spell-Checker
using String Editing

The Problem: When a user types "algorythm", how does the computer know to suggest "algorithm" and not "algebra"?

The Solution: It mathematically calculates the cheapest way to fix the word using the Minimum Edit Distance algorithm — a classic Dynamic Programming approach.

The backbone of Grammarly, MS Word, and Google autocorrect — Levenshtein Distance with custom costs.

StringEdit Algorithm
Algorithm StringEdit(X,Y,n,m) // D=delete, I=insert, C=change cost { M[0,0]:=0 for i:=1 to n do M[i,0]:=M[i-1,0]+D(x[i]) for j:=1 to m do M[0,j]:=M[0,j-1]+I(y[j]) for i:=1 to n do { for j:=1 to m do { M[i,j]:=min( M[i-1,j]+D(x[i]), // del M[i-1,j-1]+C(x[i],y[j]),// chg M[i,j-1]+I(y[j])) // ins }} return M[n,m] }

D(xi)=1 delete · I(yj)=1 insert · C(xi,yj)=2 sub (0 if match)

Complexity Analysis

O(m × n)
Time

Compute every cell in the m×n matrix.

O(m × n)
Space

Store the 2D matrix for subproblems.

Space Optimization

Reducible to O(min(m,n)) — store only two rows.

Principle of Optimality

Optimal solution to the whole string depends on optimal solutions of its substrings.

Application 2 — Slide 01 / 04

DNA Sequence Alignment

The Problem: Biologists need to compare DNA strands to find mutations, measure evolutionary distance, and identify disease markers. How do you quantify how "different" two sequences are?

The Key Insight: DNA mutations are exactly the same three operations — substitutions (point mutations), insertions, and deletions (indels).

This is the exact same StringEdit algorithm — just with nucleotides A, C, G, T instead of alphabet letters.

Application 2 — Slide 02 / 04

Same Algorithm, Different Domain

Spell Checking
Input:"algy" → "algo"
Symbols:a–z alphabet
D(xi):1 delete letter
I(yj):1 insert letter
C(xi,yj):2 substitute letter
DNA Alignment
Input:"ACGTAC" → "ACGTC"
Symbols:{A, C, G, T}
D(xi):1 gap (deletion)
I(yj):1 gap (insertion)
C(xi,yj):2 mismatch; 0 if match
Identical pseudocode. The algorithm doesn't care what symbols it processes — only the cost function.

Application 2 — Slide 04 / 04

Why DNA Alignment Matters

Evolutionary Biology

Measure evolutionary distance between species. Humans and chimpanzees share 98.8% sequence similarity.

Medical Diagnostics

Identify disease-causing mutations by comparing a patient's DNA against a reference genome. Edit distance pinpoints exactly where and how sequences differ.

Virus Tracking

Track how viruses like SARS-CoV-2 mutate over time by computing edit distances between sequential genome samples.

The Power of Abstraction

One DP algorithm. Two completely different fields. Spell checking and genome sequencing share the exact same mathematical foundation — that's the beauty of Dynamic Programming.

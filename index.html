Intelligent Spell-Checker
using String Editing

The Problem: Every day, millions of users make typos. When a user types "algorythm", how does the computer know to suggest "algorithm" and not "algebra"?

The Solution: It doesn't guess. It mathematically calculates the "cheapest" way to fix the word using the Minimum Edit Distance algorithm — a classic Dynamic Programming approach.

This is known as the Levenshtein Distance with custom costs — the backbone of tools like Grammarly, MS Word, and Google Search autocorrect.

Slide 02 / 05

The Core Concept: Three Edit Operations

The algorithm calculates the minimum total cost to transform String A (the typo) into String B (a valid dictionary word) using three operations:

Insertion
Add a missing letter
algo → algos
Cost: 1
Deletion
Remove an extra letter
algoo → algo
Cost: 1
Substitution
Swap a wrong letter
algy → algo
Cost: 2
Goal: Compare the typed word against dictionary words and suggest the one with the lowest total edit cost.

The Algorithm & DP Matrix

StringEdit Algorithm
Algorithm StringEdit(X, Y, n, m) // X, Y are strings of length n, m // D(xi) = deletion, I(yj) = insertion, // C(xi,yj) = change/substitution cost { M[0, 0] := 0 // two empty strings for i := 1 to n do M[i, 0] := M[i-1, 0] + D(x[i]) for j := 1 to m do M[0, j] := M[0, j-1] + I(y[j]) for i := 1 to n do { for j := 1 to m do { M[i,j] := min( M[i-1, j] + D(x[i]), // delete M[i-1, j-1] + C(x[i],y[j]), // change M[i, j-1] + I(y[j]) // insert ) } } return M[n, m] }
Our Cost Mapping
D(xi)=1(delete any character)
I(yj)=1(insert any character)
C(xi,yj)=2(substitute; 0 if xi = yj)

Algorithmic Complexity Analysis

O(m × n)
Time Complexity

Where m is the length of the typed word and n is the length of the dictionary word. We compute a value for every cell in the m × n matrix.

O(m × n)
Space Complexity

We store the 2D matrix to track overlapping subproblems.

Space Optimization (Bonus)

Space can be reduced to O(min(m, n)) by only storing the two most recent rows — proving deep understanding of DP optimization.

Principle of Optimality

This algorithm satisfies DP requirements because the optimal solution to the whole string relies entirely on the optimal solutions of its substrings. Each cell's value depends only on already-computed neighboring cells.

Slide 05 / 05

Why It Matters

Scale

While comparing two words is fast (a tiny matrix), MS Word or Grammarly must compare your typo against thousands of dictionary words in a fraction of a second — and do this for every single keystroke.

Engineering Reality

Real systems add BK-trees, n-gram indexing, and frequency ranking on top of edit distance to narrow the search space. But edit distance remains the fundamental scoring mechanism.

Conclusion

Dynamic Programming gives us a structured, non-recursive way to solve complex string matching instantly — making modern text-editing software possible. It transforms an exponential brute-force problem into a clean, efficient O(m×n) solution.

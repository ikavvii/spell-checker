How it works

  1. The typed word is compared against every word in the dictionary.
  2. For each pair, a DP matrix of size (m+1)×(n+1) is computed.
  3. Each cell dp[i][j] = minimum cost to transform the first i characters of the typed word into the first j characters of the dictionary word.
  4. Bottom-right cell = total edit distance. The dictionary word with the lowest distance is the best suggestion.
dp[i][j] = dp[i-1][j-1]            if s[i-1] == t[j-1] (match — free)
dp[i][j] = min( dp[i-1][j] + 1,  dp[i][j-1] + 1,  dp[i-1][j-1] + 2)   otherwise
